# Documentos

A API já guarda o arquivo. Esta fatia só abre a tela.

- Lista da criança: nome, categoria e tamanho. Sem a chave do disco
- Busca filtra essa lista por nome ou categoria. Não há parâmetro novo na API
- Enviar pede categoria e arquivo. Categoria vazia ou maior que 40 não sai
- Tipos aceitos pela API: PDF, JPEG, PNG e WebP, até 10 MB
- Baixar pede o arquivo com o token e usa o nome original
- Sem apagar. Documento não entra na linha do tempo
